# ZDF Mediathek

Dieses Modul durchsucht öffentlich zugängliche ZDF-, ZDFneo- und
ZDFinfo-Inhalte über den begrenzten MediathekViewWeb-Index und übergibt die
gewählte Senderquelle an den zentralen OpenR4d10-Player. Es benötigt weder
Konto noch Zugangsdaten.

Die Ergebnisliste enthält keine Streamadressen. Suche und Antwortgröße sind
begrenzt; DRM, Geoblocking und Altersfreigaben werden nicht umgangen.
